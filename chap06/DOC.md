# Git ブランチについてのドキュメント

## ブランチとは

ブランチは，Gitにおいて並行して作業を進めための機能です．
複数の開発ラインを同時に管理できます．

## ブランチの利点

- 安全に新機能を開発できる
- メインの開発ラインに影響をあずに実験できる
- 複数の作業を同時に進めることが可能

## 基本的なコマンド

### ブランチの作成

```bash
git switch ブランチ名
```

### ブランチの切り替え

```bash
git branch ブランチ名
```

### ブランチの一覧表示

```bash
git branch
```

## ブランチの仕組み

ブランチは，コミットを指すポインタです．
実際には，`.git/refs/heads` ディレクトリに保存されている
テキストファイルで，その中にはコミットIDが記録されてます．

HEADブランチは，現在いる最新のコミットを指すポインタです．
HEADブランチは，`.git/HEAD` ファイルに保存されています．

これにより，ブランチの作成や切り替えが非常に高速に行われます．
