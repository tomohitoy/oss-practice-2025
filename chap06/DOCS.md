# Git ブランチについてのドキュメント

## ブランチとは

ブランチは、Gitにおいて並行して作業を進めるための機能です。
複数の開発ラインを同時に管理することができます。

## ブランチの利点

- 安全に新機能を開発できる
- メインの開発ラインに影響をあたえずに実験できる
- 複数の作業を同時に進めることが可能

## 基本的なコマンド

### ブランチの作成

```bash
git branch ブランチ名
```

### ブランチの切り替え

```bash
git switch ブランチ名
```

### ブランチの一覧表示

```bash
git branch
```

## ブランチの仕組み

ブランチは、コミットを指すポインタです。
実際には、`.git/refs/heads` ディレクトリに保存されている
テキストファイルで、その中にはコミットIDが記録されてます。

これにより、ブランチの作成や切り替えが非常に高速に行われます。
